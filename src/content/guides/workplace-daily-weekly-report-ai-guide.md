日报和周报看起来像两个页面，但真正的问题是同一个：如何把零散工作记录整理成真实、清晰、可复核的汇报。为了避免“AI 写日报”和“AI 写周报”两类内容过度拆分，本指南把它们放在同一个工作流里说明：什么时候写日报，什么时候写周报，如何准备输入，如何判断 AI 输出是否夸大。

## 日报、周报和项目同步有什么区别

| 类型 | 适合场景 | 重点 | 不适合写法 |
| --- | --- | --- | --- |
| 日报 | 每天同步进度、问题和明日计划 | 今日完成、阻塞、明日动作 | 把所有聊天记录流水账堆上去 |
| 周报 | 每周总结成果、数据、风险和下周重点 | 结果、阶段进展、风险和资源需求 | 把每天日报简单拼接 |
| 项目同步 | 跨团队同步项目状态 | 里程碑、依赖、决策和待协调事项 | 只写个人工作，不写项目影响 |

如果公司要求每天写，优先用 [AI 写日报 Prompt](/prompts/ai-daily-report-prompt/)；如果是每周向领导或团队汇报，优先用 [AI 写周报 Prompt](/prompts/ai-weekly-report-prompt/)。如果你要汇总多人进展，可以把日报或周报作为原始输入，再让 AI 按项目归类。

## Before / After：低密度输入和高密度输入

### Before：低密度输入

```text
今天改了页面，参加会议，明天继续优化。
```

这个输入太少，AI 只能补通用话术，容易输出：

```text
今日完成页面优化工作，并参与相关会议讨论，明日将继续推进优化。
```

这类汇报看起来顺，但信息价值很低。

### After：高密度输入

```text
今天完成：
- 修改首页 Prompt 区块，把完整模板改成场景卡片，避免首页堆长 Prompt。
- 给文章页增加作者与人工复核说明。
- n8n 教程增加一个可下载 JSON 模板。

验证：
- npm run build 通过。
- npm run check:seo 通过。

问题：
- 日报和周报 Prompt 页面结构相似，需要新增综合指南并互链。

明天：
- 扩写 Prompts / Skills / Agents 列表页介绍。
- 检查 sitemap 是否继续排除 tags。
```

AI 可以整理成：

```markdown
## 今日完成
- 优化首页 Prompt 展示方式，将完整模板改为场景卡片，降低重复内容风险。
- 在文章页增加作者与人工复核说明，增强内容可信度。
- 为 n8n 教程补充可下载 JSON 模板，提升工具页面实用价值。

## 验证结果
- 已运行 `npm run build` 和 `npm run check:seo`，均通过。

## 问题与风险
- 日报和周报 Prompt 页面结构相近，存在内容拆分过细的问题，需要通过综合指南和内链合并搜索意图。

## 明日计划
- 扩写 Prompts、Skills、Agents 列表页的选择逻辑和内容质量说明。
- 复查 sitemap 和 noindex 规则，确保薄标签页不进入索引。
```

## 通用 Prompt：日报 / 周报都可用

```text
你是一名职场汇报写作助理。请根据我提供的原始工作记录，整理成一份真实、克制、结构清晰的工作汇报。

请先判断更适合输出为：日报 / 周报 / 项目同步。

请输出：
1. 汇报类型判断
2. 核心成果或今日完成
3. 重点进展
4. 数据或验证结果
5. 问题、风险和影响
6. 下一步计划
7. 需要协同或确认的事项

要求：
- 不要夸大成果
- 不要把未完成写成已完成
- 没有数据时不要编造数据
- 风险要说明可能影响
- 信息不足时用“待补充”标记
- 语言适合发给直属领导或项目组

原始记录：
[粘贴日报、周报或项目记录]
```

## 边界条件和踩坑提醒

| 风险 | 表现 | 修正方式 |
| --- | --- | --- |
| 夸大成果 | “显著提升”“全面完成”但无数据支撑 | 改成“完成了某项动作，效果待验证” |
| 隐藏风险 | 未完成事项被写得很轻 | 写清楚影响、依赖和需要谁协助 |
| 计划空泛 | “继续推进优化” | 改成具体动作、对象和验收结果 |
| 泄露敏感信息 | 客户名、合同、账号、内部数据直接出现 | 发送前脱敏或删除 |
| 日报拼成周报 | 每天事项堆叠，没有总结 | 按项目、目标和结果重新归类 |

## 发送前检查清单

- 是否把事实、进展、风险和计划区分清楚？
- 是否有未经核对的数据？
- 是否把“参与”写成“主导”？
- 是否遗漏了需要协同的事项？
- 是否有客户、合同、账号或隐私信息？
- 是否符合团队固定格式？
- 是否需要缩短为 300 字以内版本？

## 小结

日报和周报不应该变成 AI 生成的漂亮套话。真正有价值的职场汇报，是把真实记录变成清晰结构：做了什么、产生什么结果、哪里有风险、下一步需要什么支持。AI 可以帮你整理语言，但最终事实、数据和边界必须由人确认。
